# GPT Sites

Site web fait en React + Vite, exécutable en local sans dépendance externe d'API.

But du site : 

## Lancer en local

1. Installer les dépendances

```bash
npm install
```

2. Démarrer le serveur de développement

```bash
npm run dev
```

3. Ouvrir l'URL affichée dans le terminal (en général http://localhost:5173)

## Build de production

```bash
npm run build
npm run preview
```
